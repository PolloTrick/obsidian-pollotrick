# LLM y NLP

El procesamiento de lenguaje natural (NLP) permite trabajar con texto y habla. Un modelo de lenguaje grande (LLM) predice tokens —fragmentos de texto— a partir de su contexto, normalmente usando una arquitectura transformer.

## Flujo simplificado

1. **Tokenización:** convertir texto en unidades numéricas.
2. **Preentrenamiento:** predecir el siguiente token en grandes colecciones de texto.
3. **Ajuste:** adaptar el comportamiento a instrucciones, tareas o dominios.
4. **Inferencia:** generar una respuesta token por token.
5. **Evaluación:** medir utilidad, fidelidad, seguridad y coste.

## Preguntas para estudiar un LLM

- ¿Qué datos y objetivo de entrenamiento se usaron?
- ¿Cuál es el contexto máximo y cómo afecta las respuestas?
- ¿Qué mecanismo reduce alucinaciones?
- ¿Qué evaluación respalda sus capacidades?
